## 五、故障预案（云端适配）

| # | 故障 | 症状 | 应对 | 状态 |
|---|------|------|------|------|
| 1 | 现场断网 | 网页打不开 / 接口超时 | 切手机热点；确认能再访问 139.9.103.86 | ☐ |
| 2 | 云端服务未起 | /health 无响应 | 联系云端管理员重启服务进程 | ☐ |
| 3 | API Key 失效 | LLM 返回 401/余额不足 | 切备用 Key；熔断器自动走兜底 | ☐ |
| 4 | 网页版卡死 | Gradio 页面空白 | 刷新页面；必要时改用接口版演示 | ☐ |
| 5 | 接口版异常 | /chat 无响应 | 退回网页版人工演示，人工朗读回复 | ☐ |
