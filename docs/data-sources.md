### 广州时期深度 + 关键转折

集中在两条线：
- **广州8个月**（1927.1-1927.9）：中山大学任教、四·一五事变、辞职、创作《而已集》、与许广平关系、迁居白云楼等
- **人生关键转折**：弃医从文(1906)、发表《狂人日记》(1918)、避难(1926-1927)、左联盟主(1930)等

### 采集要点

- 每条生平记录必须有 `year` 字段
- 重点关注与广州相关的时间段（1927年1月-9月）
- 人物关系要准确：许广平、周作人、瞿秋白、柔石、萧红等
- 标注事件背景，不只是罗列日期

### 采集要点

- persona 不是语录，而是**描述性文字**：鲁迅说话是什么风格？用什么词？情绪怎样？
- 聚焦可操作的 Prompt 特征：常用虚词（大抵/大约/然而/竟/却）、句式特点（短促有力、反讽）、情绪基调（冷峻、深刻、忧愤）
- 同时采集"鲁迅讨厌什么风格的表达"（反例同样有价值，用于 Prompt 负面约束）
- 标记 `character_voice: true`
